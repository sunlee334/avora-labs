# 성능 기준선

`node scripts/measure-vitals.mjs` 로 잰 값입니다. 재려면 먼저 빌드된 결과물을
띄워야 합니다 — `astro dev` 로 재면 개발 도구 스크립트가 섞여 들어와 숫자가
쓸모없어집니다.

```
npm run build
npx wrangler dev --port 4321 --local &
node scripts/measure-vitals.mjs
```

> ⚠️ **아래 숫자는 로컬 값이고, 운영에는 여기 없는 것이 하나 더 실립니다.**
>
> 측정 스크립트는 `BASE_URL` 이 없으면 `http://localhost:4321` 을 봅니다.
> 그런데 GA4 는 `location.hostname === 'avoralabs.co'` 일 때만 뜨므로,
> **`gtag/js` 는 이 표에 한 번도 들어온 적이 없습니다** — 실측 170,522 B(br),
> `cache-control: private, max-age=900` 이라 15분마다 다시 받습니다.
>
> 지금은 그것을 `load` 뒤로 미뤄 두어 첫 화면과 다투지는 않습니다
> (`Base.astro`). 그래도 전송량 항목은 운영에서 더 큽니다.
>
> 운영 값을 보려면 `BASE_URL=https://avoralabs.co node scripts/measure-vitals.mjs`
> 로 재세요. 그 숫자를 표에 넣을 때는 **어느 쪽인지 반드시 적어 두세요.**

## 알아 둘 것

**가장 큰 파일은 사진이 아니라 한글 글꼴입니다.** `body.woff2` 가 모든
화면에 실립니다.

> 이 숫자는 그동안 조용히 커졌습니다. 2026-08-31 에 적을 때는 108KB 였고,
> 지금은 **120,920 B** 입니다. 비한국어 4개는 한 커밋에서 22~29% 늘었습니다 —
> `1c2a1fe 푸터의 사업자 정보가 다른 서체로 떨어지고 있었다`. 영어판 푸터에도
> 한글 표기(통신판매업)가 들어가야 하니 **버그가 아니라 트레이드오프**입니다.
>
> 다만 `npm run check:fonts` 는 **최신 여부만** 보고 크기는 보지 않습니다.
> 그래서 이 증가가 아무 데도 걸리지 않았습니다. 글꼴은 `preload` 로 나가므로
> 커지면 LCP 와 직접 다툽니다 — 다음에 늘어날 때 알 수 있게 상한을 걸어 두는
> 편이 낫습니다. 이미 쓰는 글자만 골라낸 뒤의 크기이고(`npm run fonts`), 한글은
글자 수 자체가 많아 여기서 더 줄이려면 쓰는 글자를 줄여야 합니다.

**히어로 사진의 선명도는 원본이 한계입니다.** 원본이 1,600px 인데 DPR 3 휴대폰
(아이폰 Pro 등)은 2,649px 를 필요로 합니다. `sizes` 로는 더 못 갑니다 — 더 큰
원본이 있어야 합니다. 실촬영 이미지를 받을 때 **가로 2,600px 이상** 으로
요청하세요.

`sizes` 값 자체는 한 번 틀렸다가 고쳤습니다. `object-fit: cover` 가 세로를
채우려고 사진을 키우기 때문에, 화면 폭이 390px 이어도 필요한 사진 폭은 그
2.3배입니다. `100vw` 라고 적었더니 브라우저가 780px 짜리를 받아 늘려 그렸고,
선명도가 4분의 1이었습니다(라플라시안 분산 12.4 → 49.1). 자세한 계산은
`src/pages/[lang]/index.astro` 의 히어로 주석에 있습니다.

**같은 한계가 히어로 말고도 있습니다.** `.figure`(`cover` + `height: 58svh`)를
쓰는 사진들도 같은 계산을 받는데, 원본이 거기까지 못 미칩니다:

| 사진 | 원본 | 390/DPR2 에 필요한 폭 |
|---|---|---|
| `water-droplets` | 1200×675 | 1,740px — **원본에 없음** |
| `panel-skin` | 1600×1066 | 1,469px — 원본 안 |
| `skin-sweat` | 1200×1750 | 780px — 이미 충분(세로 원본) |

`sizes` 만 고쳐도 달라지지 않습니다 — `widths` 상한이 780w 라 브라우저가
어차피 그것을 고릅니다. 즉 이건 "값을 고치는 일" 이 아니라 **"더 큰 파일을
보내는 일"** 이고, 화면 아래에서 lazy 로 뜨는 장식 사진이라 검색 순위에
주는 영향은 없습니다. 지금은 가벼운 쪽을 택하고 그대로 둡니다.

**실촬영본을 받을 때 정리됩니다.** 위의 히어로 요청(가로 2,600px 이상)을
`water-droplets`·`panel-skin` 에도 같이 걸어 두세요. 원본이 커지고 나면 그때
`widths` 와 `sizes` 를 함께 올리는 것이 맞습니다 — 원본이 작은 채로 올리면
없는 픽셀을 늘려 보내는 것이라 용량만 늘고 선명해지지 않습니다.
